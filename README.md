# 검은 복음서 — GitHub Pages

친구들끼리 즐기는 밈/풍자 콘셉트의 정적 웹페이지입니다.

## GitHub Pages에 올리는 방법
1. GitHub에서 새 저장소(repository)를 만듭니다.
2. `index.html`과 `assets/` 폴더를 저장소 최상위(root)에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` / `/(root)`를 지정한 뒤 저장합니다.
5. 잠시 기다리면 Pages 주소가 표시됩니다.

사진 속 인물이 불편해하면 사진을 삭제하거나 페이지를 비공개로 전환하세요. 이 페이지는 실제 종교나 인물의 신념을 주장하지 않는 풍자물입니다.
